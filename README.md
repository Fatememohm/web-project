# 📌 پروژه پایانی درس برنامه‌نویسی وب

## 🎓 Web Programming Final Project

---

## 🧾 معرفی پروژه

این پروژه به عنوان پروژه پایانی درس **برنامه‌نویسی وب** پیاده‌سازی شده است.
هدف اصلی پروژه، طراحی و توسعه یک **سامانه تحت وب شامل صفحه ورود (Login) و داشبورد مدیریتی (Dashboard)** با اتصال به API خارجی و مدیریت داده‌ها می‌باشد.

در این پروژه ارتباط با API از طریق یک سرور Node.js برقرار شده و درخواست‌ها با استفاده از Proxy به API اصلی هدایت می‌شوند تا مسائل امنیتی و CORS مدیریت شوند.

---

## 🏗 معماری پروژه

پروژه از سه بخش اصلی تشکیل شده است:

### 1️⃣ بخش فرانت‌اند (Frontend)

* طراحی رابط کاربری Login
* طراحی داشبورد مدیریتی

* مدیریت توکن احراز هویت

### 2️⃣ بخش بک‌اند سبک (Node.js Server)

یک سرور ساده با استفاده از Express پیاده‌سازی شده که:

* فایل‌های استاتیک را سرو می‌کند
* درخواست‌های `/api` را به API اصلی Proxy می‌کند
* مشکل CORS را حل می‌کند
* امکان استقرار راحت روی Liara را فراهم می‌کند

فایل مرتبط:

```

```

## 🔐 احراز هویت (Authentication Flow)

فرآیند احراز هویت به صورت زیر انجام می‌شود:

1. کاربر در صفحه Login اطلاعات خود را وارد می‌کند.
2. درخواست به مسیر `/api/token` ارسال می‌شود.
3. سرور Express درخواست را به API اصلی Proxy می‌کند.
4. در صورت موفقیت، توکن دریافت شده و در مرورگر ذخیره می‌شود.
5. کاربر به داشبورد هدایت می‌شود.
6. تمامی درخواست‌های بعدی با استفاده از توکن انجام می‌شوند.
