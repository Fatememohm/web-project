سامانه هاویر کشت

پروژه پایانی درس طراحی وب

 معرفی پروژه

سامانه هاویر کشت یک پروژه دانشجویی در درس «طراحی وب» است که با هدف طراحی رابط کاربری یک سامانه و اتصال آن به API ارائه‌شده پیاده‌سازی شده است.

تمرکز این پروژه بر پیاده‌سازی بخش Front-End، مدیریت احراز هویت کاربران و برقراری ارتباط صحیح با API بوده است.

روند انجام پروژه (مرحله‌به‌مرحله)

در این بخش، مراحل انجام پروژه به صورت عملی توضیح داده شده است.

1️ طراحی صفحه ورود (Login)

در ابتدا صفحه ورود طراحی شد که شامل:

فرم دریافت نام کاربری و رمز عبور

طراحی ظاهری با CSS

آماده‌سازی ساختار برای ارسال درخواست به API

پس از تکمیل طراحی، بخش JavaScript برای ارسال اطلاعات ورود اضافه شد.

2️ پیاده‌سازی فرآیند ورود و دریافت توکن

در این مرحله:

اطلاعات فرم از کاربر دریافت شد

درخواست به API ارسال شد

در صورت موفق بودن، توکن دریافت شد

توکن در LocalStorage ذخیره شد

این توکن برای احراز هویت در درخواست‌های بعدی استفاده می‌شود.

3️ طراحی صفحه داشبورد

پس از ورود موفق، کاربر به صفحه Dashboard هدایت می‌شود.

در این صفحه:

ساختار کلی نمایش داده‌ها طراحی شد

بخش‌های مختلف اطلاعاتی در نظر گرفته شد

ظاهر صفحه با CSS تنظیم شد

4️ ارسال درخواست‌های احراز هویت‌شده

در صفحه داشبورد:

توکن ذخیره‌شده از LocalStorage خوانده می‌شود

درخواست‌های API همراه با Authorization Header ارسال می‌شوند

پاسخ API دریافت و در صفحه نمایش داده می‌شود

5️ حل مشکل CORS و راه‌اندازی Proxy

در ابتدا اتصال مستقیم به API باعث خطای CORS در مرورگر شد.

برای حل این مشکل:

یک سرور محلی با Node.js ایجاد شد

از Express برای مدیریت سرور استفاده شد

با استفاده از http-proxy-middleware مسیر /api به API اصلی متصل شد

به این ترتیب درخواست‌ها ابتدا به سرور محلی ارسال شده و سپس به API اصلی منتقل می‌شوند.

6️ تست و بررسی نهایی

در مرحله پایانی موارد زیر بررسی شد:

عملکرد صحیح ورود کاربر

ذخیره و بازیابی توکن

ارسال صحیح درخواست‌های احراز هویت‌شده

مدیریت خطاهای احتمالی

اجرای صحیح پروژه در محیط لوکال

نحوه احراز هویت

فرآیند احراز هویت در پروژه به این صورت انجام می‌شود:

کاربر اطلاعات ورود را وارد می‌کند.

اطلاعات به API ارسال می‌شود.

در صورت موفقیت، توکن دریافت می‌شود.

توکن در LocalStorage ذخیره می‌شود.

درخواست‌های بعدی همراه با توکن ارسال می‌شوند.

اجرای سرور:

node server.js


سپس در مرورگر:

http://localhost:3000
